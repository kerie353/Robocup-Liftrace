# 已知H中心坐标兜底候选（2026-10-16）

来源：导航仓 liftrace_board_trial_20260928，基于 f78ca923。用户授权增加已知H中心降落兜底并由开发者拟定时间阈值。本次未上板、未实飞，不表示现场已启用。

## 原入口默认

04/08、继承08策略的03/10使用视觉对准、固定中心下降和POSCTL交接。三套已登记整场场地的捕获高度为FC AGL1.1m（通用08 settings仍为1.2m，由site覆盖）。08/10（03继承08）默认vh：水平误差不超过6cm、水平速度低于0.1m/s，持续约1秒并有有效H观测；D2固定XY下降。08/10当前POSCTL目标FC AGL0.35m，交接高度上限0.50m；低位交接保留既有反馈新鲜度与短时窗口，不新增XY/速度门槛。04走廊接H保持原non_vh/D1，目标0.35m、交接上限0.40m；本次未统一这些旧差异。切POSCTL后不再持续消费H视觉目标，仍按现有飞手油门/飞控位置模式完成末段，不等价于AUTO.LAND。

## 新兜底

1. 到原LAND命令提供的实测H点XY 20cm以内、捕获高度差15cm以内，开始计时。转场途中不计时。
2. 15秒内视觉成功，优先用原视觉确认中心。选15秒是给正常约数秒的对准留余量，同时避免整段动作预算耗在没有可用H观测上；尚未经动态标定。
3. 满15秒且仍未确认视觉，锁定坐标兜底模式，返回原LAND实测H中心；不再追随后续视觉中心。
4. 当前位姿与里程计到预设H误差均≤8cm，捕获高度差≤15cm、水平速度≤0.1m/s，以不同的新鲜里程计样本连续满足0.30秒，才进入原下降链。
5. 固定预设H中心，复用各入口当前下降模式与POSCTL交接；不伪造视觉观测、不刷新旧视觉时间戳。取消/新LAND事务重置兜底，原动作超时、位姿失效及接管规则保留。

计时以首次到达为起点，随后漂移不会重新开始15秒；真正下降仍须重新达到第4项。超时本身不是无条件下降许可。如果堵在低位POSCTL交接，本功能不绕过该条件。已知H坐标的测量误差、坐标漂移会影响兜底落点，视觉成功时仍优先视觉。

## 配置

`deployment/board_trials_4x4/04_corridor_landing/settings.yaml`、`08_full_mission/settings.yaml`显式开启；03/10沿用08加载逻辑。site可覆盖以下块，公共库默认关闭，仿真配置转换强制关闭：

```yaml
landing_coordinate_fallback:
  enabled: true                   # 仅已有实测H坐标的POSCTL实机入口
  wait_sec: 15.0                   # 到H观察位置后等待视觉确认
  arrival_xy_tolerance_m: 0.20     # 开始计时的水平到达范围
  arrival_z_tolerance_m: 0.15      # 开始计时及下降前的观察高度容差
  descend_xy_tolerance_m: 0.08     # 兜底下降前到实测H的水平误差
  max_horizontal_speed_mps: 0.10  # 兜底下降前的水平速度
  stable_duration_sec: 0.30       # 只累计不同的新鲜里程计样本
```

参数生成位置为`control.external_landing.coordinate_fallback`。切AUTO.LAND或OFFBOARD实验模式需显式关闭此兜底，避免误继承。
