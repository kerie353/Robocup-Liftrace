# 投递下降三种模式

2026-10-12；分支 `liftrace_board_trial_20260928`。默认模式1，保留当前三轴位置控制。

## 选择方式

08整场试飞编辑 `deployment/board_trials_4x4/08_full_mission/settings.yaml`；正式比赛编辑使用的场地 YAML（示例为 `deployment/competition/field.example.yaml`）：

```yaml
drop_descent_mode: 1         # 1 / 2 / 3
drop_descent_speed_mps: 0.20 # 模式2、3的Z指令下降速度，单位m/s
```

重新生成配置后，控制器读取：

```yaml
drop_system:
  descent:
    mode: 1
    speed_mps: 0.20
    max_step_dt_sec: 0.20
    zero_velocity_setpoint_topic: /navigation/drop_setpoint_vertical
```

参数在节点启动时加载；模式必须为整数1/2/3，下降速度必须为有限数且在(0,1]m/s。候选默认0.20m/s仅表示Z指令轨迹斜率，不保证飞机实际速度。模式1不使用独立Z速度参数。

## 模式含义

| 模式 | 水平控制 | 垂直控制 | 输出 |
|---|---|---|---|
| 1 | 继续追踪冻结补偿XY | 原投递高度终点及通用三维前视限距 | 原XYZ位置话题 |
| 2 | 始终使用冻结的补偿XY | 独立Z高度轨迹，不经过XYZ三维插值 | 原XYZ位置话题 |
| 3 | 忽略XY位置；VX=0、VY=0 | 与模式2相同的独立Z高度轨迹 | 原始PositionTarget，Z位置+XY速度 |

三种模式只在投递下降、等待释放和等待成功回执阶段区分输出；其他运动保持原控制。前置视觉捕获、槽位补偿、双XY≤4cm及最大水平速度≤0.1m/s连续1秒、无窗口位移、最终高度门控及许可规则保持不变。成功ACK后退出独立下降通道，恢复既有上升与下一目标流程。H降落模式另行配置，不由这些参数改变。

## 模式2、3的Z轨迹

下降准入时从当前有效高度和观察高度中的较低值开始，最低为投递终点；后续每拍按独立时钟降低Z指令，最低收敛到 `release_setpoint_height`。没有按实际XY偏移或导航前视距离缩放Z，也不把高度反馈噪声逐帧当作新起点。

反馈不新鲜或飞行控制状态无效时不继续推进Z轨迹。控制间隔超过0.20s时保持最后Z指令，不一次补发整个缺帧期间的下降量。保持最近高度指令不等于实际飞机立刻停止。新冻结、两种动作reset及任务撤销清理轨迹；无效任务和边界保护回到原位置保持通道。下降反弹不会自动爬回观察高度。

## 模式3的消息与互斥

控制器发 `/navigation/drop_setpoint_vertical`，任务/飞控坐标适配器转换后发 `/mavros/setpoint_raw/local`。原始包有效字段为Z位置、VX/VY零速度和yaw；忽略PX/PY、VZ、全部加速度及yaw_rate，type_mask=2531。它仍有水平速度闭环，并非水平完全不受控制。

模式3的XY仅作为坐标变换锚点，转换后不作为飞控XY目标。变换必须保持重力方向，仅允许绕Z轴旋转和平移；倾斜/翻转变换拒绝发布。MAVROS负责ENU/NED转换，不手工反转Z。

位置、H垂直和投递零速度通道共用互斥锁及成功发布的时间戳水位，防止迟到的旧位置/原始包覆盖更新的命令。每次控制拍仅选择一种通道。模式3不是复用H的无XY位置/速度反馈包，H的原始目标构造函数保持原样。
