# 投递下降前水平门控

2026-10-12；基于 `liftrace_board_trial_20260928` 的 `421e6023`。

用户指定：飞控中心和投口水平位置误差均不超过 4 cm，水平速度上限 0.1 m/s，连续满足 1 秒；不检查窗口位移。本次仅改补偿投递下降入口，H、起飞、路线、三维限距和最终释放规则保持原逻辑。

## 实现

独立 `DropPreDescentStabilityWindow` 接在既有 `compensatedDropSettled(true, ..., false)` 下降入口。使用同一条新鲜里程计的完整姿态，将速度变换到任务坐标；水平速度取飞控中心速度及 `v + ω × arm` 的投口速度的最大值。双 XY 误差也取最大值，4 cm 与 0.1 m/s 边界允许相等。

连续区间使用不同源时间戳的里程计样本，并同时满足源时间、接收时间和控制时间跨度至少 1 秒。重复读取同一帧不能推进区间；速度/误差超限、陈旧反馈、控制无效或身份变化重置。超过 0.2 秒的样本间隙重新计时，至少 3 个不同样本。冻结、新动作、取消/失效的原保持路径和两种 reset 都清除独立窗口。没有位移、Z 误差或竖直速度门控。

新参数位于两份控制 YAML 的 `drop_system/pre_descent`：

```yaml
xy_tolerance_m: 0.04
max_horizontal_speed_mps: 0.10
stable_duration_sec: 1.0
max_odom_age_sec: 0.20
max_sample_gap_sec: 0.20
min_samples: 3
```

最终释放仍使用 `drop_system/settle` 的原类别门限：红十字严格小于 4 cm，标准靶严格小于 6 cm；高度及许可不变。关闭既有 `compensate_before_descent` 开关仍走原兼容路径。

## 当前投递流程

1. 接受 ALIGN 并在观察高度进行视觉对准。
2. 视觉 capture 有效后冻结靶心及按槽位、姿态计算的补偿后 FC XY。
3. 保持观察高度，水平移向补偿目标。双 XY ≤4 cm 且 FC/投口最大水平速度 ≤0.1 m/s，连续保持 1 秒才放行下降。条件中断重计，不依赖冻结后的图像持续 ready。
4. 一次性进入下降阶段，继续使用冻结 XY；高度目标为既有释放高度，当前试飞设置对应 AGL 0.40 m。继续沿用原三维限距，没有新增下降暂停或轴解耦。
5. 到达既有高度窗口（当前试飞 AGL 0.35–0.45 m）、原类别 XY 门限及新鲜有效的释放许可后，请求舵机动作。下降前窗口不改变最终释放门限，也不新增最终停稳时间。
6. 异步等待匹配的成功 ACK，不自动重复调用；完成后升至配置的恢复高度，ALIGN 结束，等待 RESUME/下一目标。三投后进入既有返程路线。
