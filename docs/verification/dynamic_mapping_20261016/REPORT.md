## 静态推演中处理的问题

- 命中先于清理，保护当前前景；miss 按不同源帧去重，阻止一帧射线重复清除。
- 候选更新只改 mask，不改 hit/free；已清旧点只能被新的真实回波恢复。
- 过期是 UNKNOWN；机体盒覆盖和重建范围共同限制规划查询。
- 新观测模式始终接收有效里程计位置，避免历史深度图标志阻断位置更新。
- 清空局部地图时同时重置旧合成距离场，避免障碍已删而距离仍残留；空快照不保留旧占据。
- worker 和 reset 使用一致的锁顺序；重建失败后保持抑制，旧 worker 快照不能重新 READY。
- 地面重建先锁任务准入，再重建 FreeDOM，再推进本地代次和源时间下界；新凭据与实际地图按源时间配对，不依赖 ROS 会重写的 PointCloud2 seq。
- 新功能默认 opt-in，预留 2/4 线程对照；不将配置值写成实测结论。

## 结论边界

本轮交付是本地候选实现和离线逻辑/静态证据。尚未证明 C++ 可编译、ROS 接口运行正确、初始覆盖可用，或 Orange Pi 满负载时达到 15/200 ms 与 30 MB 目标。尤其严格未知覆盖可能阻止地面 READY/长目标规划，需要用实测可见性验证，不能靠将未知视为空闲来绕过。
