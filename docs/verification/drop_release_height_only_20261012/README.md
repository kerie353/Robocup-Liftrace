1. 视觉对准、冻结靶心和补偿 FC XY。
2. 保持观察高度进行水平补偿：FC及投口误差均≤4cm、最大水平速度≤0.1m/s，连续1秒才下降；不检查窗口位移。此门控保持 `87e67ae0` 的实现。
3. 进入下降后继续使用冻结目标和原高度控制。
4. 最终释放几何只要求当前高度进入闭区间 `[release_min_height, height_threshold]`，当前试飞生成配置对应 AGL 0.35–0.45m，目标AGL0.40m。下降后即使双XY误差反弹超过4/6cm，也不因这项误差阻塞控制器的释放请求。
5. 圆环与红十字外层判断、`executeDropAction` 服务准入均复用同一 `compensatedDropSettled(true)`，因此两处不残留原类别XY阈值门槛。下降尚未准入时，串行模式仍拒绝调用舵机。
6. 当前反馈必须数值有效且新鲜，身份/期限/飞行状态必须有效，并持有有效释放许可。近墙边界及许可仲裁、代理的原合法性判断保留；这不是绕过许可或直接调用 raw 舵机。
